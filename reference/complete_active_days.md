# Complete the active days.

If it is set to zero or or is NA, the nb of active days in the period
will be auto-generated

## Usage

``` r
complete_active_days(active_days)
```

## Arguments

- active_days:

  active days object of class
  [tibble](https://tibble.tidyverse.org/reference/tibble.html)

## Value

the curated active days table
